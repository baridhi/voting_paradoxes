# voting_paradoxes
This repository captures the data and code used in the paper titled, "Voting Paradoxes in Four Candidate Elections", with Santanu Gupta and Sanjay Sinha.

The data used in the paper comes from Lok Sabha elections at the constituency level for 2004, 2009, and 2014. These files are stored in [data](https://github.com/baridhi/voting_paradoxes/tree/main/data). This material also includes a macro-driven Excel workbook to produce key results from the paper when they were first written. However, the repository also provides Python code to replicate and reproduce the results from the paper (tables and figures), located here ([code](https://github.com/baridhi/voting_paradoxes/tree/main/code)).
